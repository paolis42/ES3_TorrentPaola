# GeekMatch Trips

GeekMatch Trips es una aplicación web desarrollada con Django que permite evaluar lugares turísticos según el nivel de interés del usuario, el precio de la actividad y el presupuesto disponible.

La aplicación utiliza SQLite como base de datos e incluye autenticación, roles de usuario, operaciones CRUD y borrado lógico.

---

## Requisitos

- Python 3.13 o compatible
- Git
